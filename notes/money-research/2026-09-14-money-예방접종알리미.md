# 2026-09-14 리서치: Money 프로젝트(예방접종알리미) 수익화/트래픽 확대

## 참고: 지난 회차(2026-09-07) 상태

동일 주제로 이미 한 차례 조사한 PR(#37, `money-research/2026-09-07-money`)이 존재하지만 **main에 병합되지
않아** 이번 세션의 `notes/money-research/` 카운트(N)에는 잡히지 않았다. 병합되지 않은 채 방치되면
다음 회차도 계속 "0번째"로 재조사하게 되므로, 대표님이 리뷰 후 병합 여부를 결정해 주셔야 카운터가
정상적으로 굴러간다. 지난 회차는 (1) `.vercel.app` 서브도메인 SEO 불리함, (2) 구글 AI Overview로 인한
정보성 검색 CTR 급감, (3) 질병관리청 공식 계산기와의 기능 중복을 지적하고, "롱테일 상황판단형 질문
콘텐츠로 전환"을 제안했다. 이번 회차는 그 제안을 그대로 반복하지 않고, **어떤 롱테일 주제가 실제로
해볼 만한지 경쟁 구도를 확인**하고 **애드센스 외 두 번째 수익원**을 조사했다.

이번 회차에서도 지난 회차와 동일하게 이 세션의 네트워크 프록시가 `yebangalimi.vercel.app`,
`kko-kkuri.com` 등 외부 사이트로의 직접 접속(WebFetch)을 차단해, 실제 페이지 소스/응답 헤더/
Search Console 상태를 직접 확인할 수 없었다 — 이 제약은 이번 세션 환경의 구조적 한계로 보이며,
**대표님이 직접 브라우저로 확인해야 하는 항목**이라는 점은 지난 회차와 동일하다.

## 요약

지난 회차가 제안한 "롱테일 상황판단형 질문 콘텐츠 4개" 후보를 그대로 실행하기 전에, 각 주제의 실제
검색 결과 상위 경쟁자가 누구인지 확인했다. 결과가 갈렸다: **"예방접종 후 미열/해열제" 계열 증상형
질문은 이미 닥터나우(의료 Q&A 플랫폼, 개별 질문마다 고유 URL로 대량 색인)가 사실상 독점**하고 있어,
신생 미니사이트가 콘텐츠 품질만으로 뚫기 매우 어려운 영역으로 보인다. 반면 **"어린이집 입소 준비/필수
서류·접종 체크리스트" 계열은 경쟁자가 육아크루(yugacrew.com), 꾸리(kko-kkuri.com) 같은 개인/소규모
운영 콘텐츠 사이트**라, 대형 플랫폼과 직접 붙는 것보다 승산이 있어 보인다 — 단, 이 판단은 구글 검색
상위 노출 목록만 본 것이라 정량적 순위·트래픽 데이터는 아니다.

또한 "수익화" 쪽에서 애드센스 하나에만 의존하지 않는 방안을 조사했다. 쿠팡파트너스는 최소 트래픽
기준이 없고 사업자등록 없이 신청 가능하며 1~3영업일 내 승인되는 것으로 확인돼, 지금 당장 신청해도
손해볼 게 없는 저리스크 액션이다. 예방접종 관련 글(체온계, 해열시럽, 접종수첩 케이스 등 구매의도가
뚜렷한 상품군)에 붙이면 애드센스처럼 페이지뷰 규모에 의존하지 않고도 소액이나마 수익을 만들 여지가
있다.

## 근거 자료

### 검증됨

1. **"예방접종 후 미열/해열제" 계열 쿼리는 닥터나우가 상위 결과를 대부분 차지** — 실제 구글 검색
   결과 확인
   - "예방접종 후 미열 해열제 먹여도 되나요" 검색 시 상위 8개 결과 중 4개가 `doctornow.co.kr/content/qna/...`
     형태(질문마다 별도 URL)였다. 의료 Q&A 플랫폼이 이런 유형의 질문을 이미 대량으로, 그것도 의료진
     답변 형식으로 커버하고 있다는 뜻이다.
   - 출처: 이번 세션 WebSearch 결과(닥터나우 4건: [예1](https://doctornow.co.kr/content/qna/ed61a3a73e7c48969c7d6a99e2ec64e3), [예2](https://doctornow.co.kr/content/qna/f0ea42f1dd184143a49da0d1314ded98), [예3](https://doctornow.co.kr/content/qna/bd83bbbcebe447a8a50d78fbe68203c5), [예4](https://doctornow.co.kr/content/qna/b92bd1216b0a43b7a84ab3ad8bc2f883))

2. **"어린이집 입소 준비/체크리스트" 계열은 소규모 개인 콘텐츠 사이트가 상위권** — 실제 구글 검색
   결과 확인
   - "어린이집 입소 필수 예방접종 체크리스트" 검색 시 육아크루(`yugacrew.com`, 대기신청 관련 글),
     꾸리(`kko-kkuri.com`, "어린이집 입소 준비: 서류·생활·적응 체크리스트")가 상위에 노출됐다.
     둘 다 대형 플랫폼이 아니라 개인/소규모 운영으로 보이는 육아정보 블로그다.
   - 출처: [육아크루 - 어린이집 입소 대기 신청](https://www.yugacrew.com/crewletter/waiting-to-enter-daycare), [꾸리 - 입소 준비 체크리스트](https://www.kko-kkuri.com/daycare-enrollment-preparation-checklist-internal-links-review/)
   - 참고: 육아크루는 별도로 "아기 예방접종 일정 계산기"(`yugacrew.com/calculator/vaccine-calculator`)도
     운영 중 — 우리 Money 프로젝트와 정면으로 같은 툴을 이미 서비스하는 경쟁자라는 뜻이다.

3. **`site:yebangalimi.vercel.app` 재검색 결과 여전히 무관한 결과만 나옴** — 이번 세션 WebSearch,
   지난 회차와 동일한 결과
   - 지난 회차(9/7) 때도 색인 안 됨 의심 신호였는데, 일주일 뒤에도 동일하다. 다만 이 역시 WebSearch
     도구가 구글 색인 전체를 대표하지 못할 가능성이 있어 **확증은 아니다** — Search Console 직접
     확인이 필요하다는 지난 회차 결론이 그대로 유효하다.

4. **쿠팡파트너스: 트래픽 최소 기준 없음, 사업자등록 불요, 1~3영업일 승인** — 복수 가이드 사이트
   교차 확인
   - 만 19세 이상 쿠팡 회원이면 사업자등록 없이 신청 가능, 특정 트래픽 수치 기준은 없으나 "콘텐츠가
     너무 적으면" 반려될 수 있어 최소한의 게시물 축적은 필요.
   - 출처: [윈들리 - 2026 ver. 쿠팡 파트너스 시작하는 법](https://www.windly.cc/blog/coupang-partners-guide), [Turtle-buff-blog - 쿠팡파트너스 하는법](https://maker.buffm.com/blog/posts/%EC%BF%A0%ED%8C%A1%ED%8C%8C%ED%8A%B8%EB%84%88%EC%8A%A4-%ED%95%98%EB%8A%94%EB%B2%95-%EA%B0%80%EC%9E%85%EB%B6%80%ED%84%B0-%EC%8A%B9%EC%9D%B8-%EC%A1%B0%EA%B1%B4-%EC%88%98%EC%9D%B5%ED%99%94-%EA%BF%80%ED%8C%81-%EC%B4%9D%EC%A0%95%EB%A6%AC), [초이스몬 - 쿠팡 파트너스 하는법](https://choicemon.com/coupang-partners-guide/)
   - 이 회사가 이미 다른 매체(예: dk-safety)에서 쿠팡파트너스를 쓰고 있는지는 확인하지 않았다 —
     신청은 계정 단위이므로 이미 계정이 있다면 신규 가입이 아니라 링크 추가만 하면 된다는 점을 참고.

5. **Google Search Console 색인 요청은 "URL 검사 → 색인 생성 요청" 반복보다 사이트맵 제출이 권장
   방법, 반영까지 통상 약 1주** — Google 공식 도움말 + SEO 가이드 교차 확인
   - 출처: [Search Console 도움말 - 페이지 색인 생성 보고서](https://support.google.com/webmasters/answer/7440203?hl=ko), [스튜디오 제이티 - 색인 생성 요청 반복해도 소용없는 이유](https://www.studio-jt.co.kr/seo-glossary/request-indexing/)

### 미검증 (근거로 사용하지 않음, 참고만)

- 닥터나우/육아크루/꾸리가 실제로 해당 키워드에서 **몇 위**인지, 월간 실제 클릭 수가 얼마인지는
  확인하지 못했다(순위추적기·서치콘솔 접근 권한 없음) — "상위 검색 결과에 누가 나오는가"라는
  정성적 관찰이지, 정량적 경쟁도 지표가 아니다.
- 쿠팡파트너스 실제 전환율/수수료율(현재 카테고리별 1~3%대로 알려짐)은 사이트마다 편차가 매우 커서,
  이번 조사에서 본 "얼마 번다"류 수치는 마케팅성 블로그 추정치라 근거로 쓰지 않았다.
- `yebangalimi.vercel.app`의 현재 robots meta / X-Robots-Tag 헤더 — 이번에도 직접 확인 불가(egress
  차단). 지난 회차 액션아이템(SEO 기초 진단)이 실제로 수행됐는지도 이번 세션에서는 확인할 방법이
  없었다.

## 액션 아이템 (이번 주 실행 가능)

1. **콘텐츠 우선순위 재조정 + 쿠팡파트너스 링크 결합**: 지난 회차가 제안한 롱테일 4개 주제 중
   "예방접종 후 미열/해열제" 같은 증상형 질문은 닥터나우가 이미 장악하고 있어 **이번 주에는 건너뛰고**,
   "어린이집·유치원 입소 전 필수 접종 체크리스트", "형제자매 동시접종 순서" 같은 **행정/체크리스트형
   주제부터 1~2개 작성**한다. 이 유형은 경쟁자가 소규모 개인 블로그 수준이라 승산이 더 높다. 글 안에
   자연스럽게 들어갈 수 있는 상품(예: 아기 체온계, 접종수첩 케이스, 상비 해열시럽)에 쿠팡파트너스
   링크를 넣을 걸 염두에 두고 초안을 쓴다(단, 링크는 항목 2 완료 후에 삽입).
2. **쿠팡파트너스 가입 신청(비용 0원, 오늘 바로 가능)**: [partners.coupang.com](https://partners.coupang.com/)에서
   신청 — 사업자등록 불요, 최소 트래픽 기준 없음, 통상 1~3영업일 승인. 승인되면 위 체크리스트 글에
   상품 링크를 추가해 애드센스 페이지뷰 의존도를 낮춘 두 번째 수익원을 확보한다. **법적 필수사항**:
   공정거래위원회 표시광고 규정상 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의
   수수료를 제공받습니다" 문구를 게시물마다 명확히 표기해야 한다 — 이 문구 없이 링크만 넣는 것은
   규정 위반이다.
