# 2026-09-23 접지저항 실측·자동판정 PR 리뷰

## 결정사항

- 접지저항 판정 기준은 화면·PDF에 적힌 **1,666.7Ω 초과**와 같은 값으로 비교한다. 50/0.03 raw float(1666.666…)와 비교하면 실측 1666.7Ω이 문구와 반대로 부적합이 된다.
- `UnitInspectionPdfData`에 `groundingResistance`가 없으면 경로 A 발급 함수에 넘길 수 없어 타입 오류다. 발급 타입과 백필 스크립트에 필드를 넣는다.
- 미방문 간이점검의 `grounding_panel_resistance`는 `simpleInspectable: false`라 체크리스트는 N/A로 남고, 실측값은 저장·2페이지 표에만 남는다. 누설전류(IGR)와 같은 기존 구조라 이번 리뷰에서 바꾸지 않았다.

## 변경된 파일

- `src/lib/unit-inspection-rules.ts` — 임계값을 소수 첫째 자리 1666.7로 고정
- `src/lib/document-pdf.tsx` — PDF 데이터 타입·미사용 satori 표에 접지저항 반영
- `scripts/backfill-unit-inspection-pdfs.ts` — 재발급 입력에 컬럼 전달

## 알게 된 것

- 방문점검 파이프라인(폼 → 워커/전기과장 API → `applyChecklistResults` → DB → AI 프롬프트 → 경로 A 1·2페이지)은 접지저항이 연결되어 있다. 마이그레이션 129 컬럼 insert/select `*`도 맞다.
- `npm run build` 통과. 판정 경계: 1666.7Ω은 적합, 1666.8Ω은 부적합.
