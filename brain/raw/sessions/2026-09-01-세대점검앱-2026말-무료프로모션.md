# 2026-09-01 세대전기점검 앱 — 2026년 말까지 전면 무료 프로모션

## 결정사항
- 세대전기점검 앱(inspect.dkansim.com)의 점검표 PDF 다운로드를 **2026년 12월 31일까지 구독 여부/30일
  쿼터와 무관하게 전면 무료**로 전환. 2027-01-01부터는 기존 정책(30일 롤링 주기당 무료 5건, 초과 시
  구독)으로 자동 복귀.
- 프로모션 기간 중 언락(다운로드)한 건은 `apartment_pdf_downloads`에 그대로 기록되므로, 2027년 이후에도
  이미 받은 건은 `already_unlocked` 판정으로 계속 무료 재열람됨 — 별도 백필 불필요.
- 세대 점검입력/AI 판정/거주자 SMS·카카오 발송은 기존과 동일하게 시기 무관 항상 무료(변경 없음).
- 우선순위는 "홍보" — 영업자료(리플릿)와 앱 내 신청/로그인/구독관리 화면에 프로모션 안내 문구 추가.

## 알게 된 것
- PDF 다운로드 게이트는 단건(`pgCheckAndConsumePdfQuota`)과 일괄 zip
  (`pgCheckAndConsumePdfQuotaBulk`) 두 함수로 나뉘어 있고 로직이 중복돼 있음 — 둘 다 프로모션 분기를
  추가해야 함(하나만 고치면 zip 경로가 여전히 쿼터를 소진시킴).
- `pgGetPdfQuotaStatus`(화면 표시용, 소비 없음)는 별도 함수라 프로모션 플래그를 여기에도 넣어야
  구독관리 화면이 정확히 표시됨.
- 영업제안서(Claude Design "우리집 안심전기 영업제안서.dc.html", 프로젝트 ID
  `8d96243c-4728-4327-b497-eec66377cef5`)는 이번 세션에서 **수정 못 함** — `claude-design` MCP가
  `FIRST_PARTY_AUTH_REJECTED`로 연결 실패(로그인 토큰에 Claude Design 권한 없음). `/design-login` 후
  재시도 필요.
