# 2026-09-23 접지저항 핸드오프 리뷰 — 데모 비밀번호 평문 삭제

## 결정사항

- `docs/collab/apt-manager-inspection/HANDOFF_TO_GROK.md`의 접지저항 PR #53 검증 기록에
  시연전용아파트 데모 계정 아이디·비밀번호가 평문으로 들어가 있었다. 저장소가 공개
  (`lakkk-cmd/dk-safety`)라 원문을 문서에서 삭제했다.
- 기능 코드(규칙엔진·경로 A PDF·페이지2 실측표)는 기록과 일치해 건드리지 않았다.
  구 satori `UnitInspectionElement`의 "접지저항 미측정" 하드코딩은 발급 경로에서
  호출되지 않는 죽은 코드라 이번 수정 범위에서 제외했다.

## 변경된 파일

- `docs/collab/apt-manager-inspection/HANDOFF_TO_GROK.md`
- `brain/raw/sessions/2026-09-23-접지저항-핸드오프-비밀번호-삭제.md`

## 알게 된 것

- 실제 PDF 발급은 `renderUnitInspectionPdf` → 경로 A + `unit-inspection-pdf-page2.tsx`다.
  페이지2 접지저항 행은 실측값과 1,666.7Ω 기준을 계산한다.
- 세대미방문 간이점검에서 `grounding_panel_resistance`는 `simpleInspectable: false`라
  체크리스트 자동판정은 방문점검에서만 적용된다. 연속입력 폼에는 입력칸이 있다.

## 미해결

- 비밀번호 원문은 이미 커밋 `fd838c0`에 남아 있다. 공개 이력에서 지우려면 이력 재작성과
  데모 계정 비밀번호 재설정이 필요하다. 이번 세션에서는 문서 원문만 제거했다.
