### CEO 추가 지시 (통합) — 방문·미방문 **공통**
1. **기타사항란**: 부하전류 · 누설전류 · 절연저항 **실측값**을 방문 세대와 **동일 형식**으로 표기.
2. **하단 확인란**: **해당 호수**와 **서명**이 보이도록 기입.
3. **담당자**: **점검자 이름** 기입 (빈칸·직책만 금지).
4. **`{아파트명} 관리사무소`**: 페이지 **맨 하단**, **잘림 0**.
5. **비고란 칸 넘침 금지 (필수 수정)**  
   - 비고(및 동일 성격의 짧은 기입란) 텍스트가 **해당 셀 경계를 한 글자도 벗어나면 실패**.  
   - 셀 bbox **클리핑** 또는 글자·줄수 축소로 **칸 안에만** 넣을 것.  
   - 칸을 키우거나 표 높이를 바꿔 원본 격자를 깨면 **0% 위반 = 실패**.  
   - 길면 문장을 줄이되, AI 논설·총평·권고를 비고에 넣지 말 것 (현장사실·숫자만).
