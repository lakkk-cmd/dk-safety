## CRITICAL FAIL 2 — 확인란 (위치)

```
┌────┬──────────┬────┐
│    │  [숫자]호 │ 인 │  ← 상단왼=숫자만+원본「호」 / 상단오른=인만
│확인├──────────┼────┤
│    │  담당자   │ 인 │  ← 하단오른=점검자명
└────┴──────────┴────┘
```

1. 해당호 = **숫자만** 상단 **왼쪽(「호」라벨) 셀 안**. 「호」중복 금지 · 「호」와 겹침 실패.
2. 상단 **오른쪽(인)** 에 호수·○○호 = 실패.
3. 점검자명 = **하단 오른쪽** 셀 안만. `담당자` 라벨 칸에 몰아넣지 말 것.
4. 셀 밖 0. 산출: `samples/crop-confirm-cells.png`

## CRITICAL FAIL 3 — 실측값 폰트 크기 ★신규

**증상:** `부하 15.2A, IGR 3.5mA, 절연 0.08MΩ` 등이 **바로 위 셀**(예: `옥내 전로의 접지선 미설치`)보다 **현저히 작음**.

**합격:**
1. 기타/비고에 넣는 **실측값 줄**의 글자 크기 = **바로 위 셀(동일 열·직상단 문구)과 동일**.
2. “작게 줄여서 맞춤”으로 위 셀보다 작아지면 **실패**.
3. 칸 밖 넘침은 FAIL 1과 동시 적용 → 동일 크기 유지 + 줄바꿈·칸 안 배치.

근거: `CEO_fail_measured_font_too_small.png`  
산출: `samples/crop-measured-font-match.png` (위 셀과 실측값 줄이 한 장에 보이도록)

## CRITICAL FAIL 4 — 확인란 해당호·점검자명 폰트 크기 ★신규

**증상:** `203`·`홍길동`이 확인란 안 **「호」·「담당자」·「인」** 등 원본 라벨보다 작음.

**합격:**
1. 상단 왼쪽 **숫자** 글자 크기 = 확인란 내 원본 라벨(「호」 등)과 **동일**.
2. 하단 오른쪽 **점검자명** 글자 크기 = 확인란 내 원본 라벨(「담당자」 등)과 **동일**.
3. 작게 찍혀 “끼워 넣은 티”가 나면 실패. 셀 밖·라벨 겹침은 FAIL 2와 동시.

근거: `CEO_fail_confirm_font_too_small.png`  
(동일 crop-confirm-cells.png에 크기 일치가 보이면 됨)
