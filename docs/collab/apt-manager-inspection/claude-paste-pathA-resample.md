### 상단 — 해당호 (숫자만)

**CEO 지시(절대):**
1. 원본 상단 **왼쪽 셀**에 이미 **「호」** 라벨이 인쇄되어 있다.
2. 기입값은 **숫자만** (예: `501`, `101`, `1504`). **「호」를 다시 쓰지 말 것.**  
   - `501호` 전체 스탬프 = **실패** (라벨「호」와 겹치거나 중복).
3. 숫자는 **상단 왼쪽 셀 안**에만. 「호」글자와 **겹치면 실패**. 여백을 두고 숫자+기존「호」가 한 셀 안에서 읽히게.
4. 상단 **오른쪽 셀(인)** 에는 호수·「○○호」를 **절대 넣지 말 것**. 인(서명)만.  
   - 지금 FAIL(`CEO_fail_confirm_unit_number_wrong_cell.png`): 오른쪽 칸에 `501호`가 찍힘.

### 하단 — 점검자명

5. **점검자 이름**(예: `홍길동`) → **하단 오른쪽 셀 안**에만.
6. `담당자` 라벨은 하단 왼쪽 원본 칸에 그대로. 이름을 담당자 칸에 몰아넣지 말 것.
7. 서명·인 이미지는 해당 **인** 칸 bbox 안. **셀 밖 0.**
