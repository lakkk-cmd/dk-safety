# 추가 붙여넣기 — 서비스·제품 품질 기준 반영

총괄이 서비스·제품팀 기준안을 HANDOFF에 추가함. 샘플에 반드시 반영:

파일: docs/collab/apt-manager-inspection/진단출력_품질기준안.md
(없으면 총괄이 채팅에 준 동일 내용)

- 2p 「실측과 기준 비교」표: 열=항목·실측·기준·판정한줄. 행=절연저항·누설전류·부하전류·접지(해당시)·차단기/ELB. 단위·미측정 명시.
- 종합총평(문단)과 권고사항(불릿 1~3, 상한5) 분리. 공포·시공지시·과태료단정·당사시공약속 금지.
- 2p 상단 고정: 「아래는 법정 점검기록표(1페이지)를 보완하는 상세 진단 안내입니다. 적합·부적합 공식 표기는 1페이지 ○×/ 를 따릅니다.」
- 사진·3단계 배지·본작업·배포 여전히 금지. 샘플 후 HANDOFF_TO_GROK 갱신하고 중단.
