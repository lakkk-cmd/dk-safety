### 작업 중 발견한 이슈 + 조치

1. **"○"(U+25CB) 폰트 렌더링 실패** — 번들 NotoSansKR 서브셋에 이 글리프가 없어 satori가
   빈 네모로 렌더링(`Failed to load dynamic font for ○` 에러 실측 확인). 텍스트 대신 CSS로
   그린 원(`ResultCircle`, border-radius 사각형)으로 대체해 해결. "×"(U+00D7)는 서브셋에
   있어 텍스트 그대로 사용.
2. **표 폭 재배분 시 높이 추정 상수 미스매치** — 위험요인 열을 만들며 처음엔 비고/점검결과
   폭을 줄였는데, `estimateTableHeight`의 줄바꿈 cpl 상수를 안 맞춰서 표 전체 높이가
   과소추정되고 하단 "관리사무소" 줄이 페이지 경계에서 잘리는 버그가 실제 렌더링에서
   나왔다. **비고(166px)·점검결과(118px) 폭은 기존값 그대로 두고, 새 열 폭은 전부
   확인사항(flex) 열에서만 가져오는 방식으로 수정**해 해결 — 확인사항 cpl도 33→31로 소폭
   하향 조정. 이 파일은 이런 "폭 바꾸면 반드시 그 열의 cpl 상수도 같이 재검증" 패턴이
   과거에도 여러 번 반복된 곳(코드 주석에 이력 있음)이라, 앞으로 이 표를 또 건드릴 땐 항상
   실제 렌더링(PNG)으로 재확인할 것.
3. **`renderUnitInspectionPdf` 호출부가 6곳**(worker/apt-manager 제출 API, admin pdf/reissue-pdf
   API, ai-diagnosis 사후보정, backfill 스크립트) — `circuitBreakerCount`를 실측/기준 계산에
   써야 해서 `UnitInspectionPdfData` 타입에 추가하고 6곳 전부에 배선했다. 기존 DB 컬럼
   재사용이라 마이그레이션 불필요.

     (기존 PDF 이중저장 게이트 패턴 재사용 가능 — `unit-inspection-pdf-storage.ts`)
