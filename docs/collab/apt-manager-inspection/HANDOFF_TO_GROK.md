## 5회차 갱신 — 2차 CEO 세부 지시 반영 (확인란 호/서명, 담당자=점검자명, 관리사무소 위치 정정)

4회차 이후 CEO가 세부 지시를 더 구체화했다. 정정한 것 3가지 + 신규 반영 2가지:

### 정정 (4회차에서 잘못 배치했던 것)

1. **"담당자" 빈칸 오배치 정정**: 4회차엔 이 칸에 "{아파트명} 관리사무소"를 넣었으나, 이번
   지시로 "담당자: 점검자 이름 기입(빈칸·직책만 금지)"이 명확해져 **점검자 이름**(예:
   "홍길동")으로 교체했다. `INSPECTOR_NAME_BLANK`(구 `MANAGER_BLANK`)로 이름도 정정.
2. **"{아파트명} 관리사무소" 위치 이동**: "페이지 맨 하단, 잘림 0"이 명확해져 원본 담당자
   칸이 아니라 **확인란 아래 여백(신규 좌표, y=55)**에 별도로 배치했다. **이 한 줄은 원본에
   사전 인쇄된 자리가 없어 "0% 배경 불변" 원칙의 유일한 예외다** — CEO가 명시적으로 지시한
   항목이라 추가했지만, 혹시 의도가 다르다면(예: 원본_세대점검표_CEO첨부.hwp에는 실제로
   이 자리가 있고 그게 어디인지) 알려주시면 좌표를 그 위치로 다시 맞추겠다. **확인 필요
   사항으로 남겨둠.**
3. **확인란 "호" 빈칸**: "해당 호수와 서명이 보이도록"에 맞춰 세대 확인란(원본 "확인|호
   ___인")에 **호수 텍스트**(예: "203호")를 채웠다. 칸이 좁아(≈32pt) "동" 없이 "호"만
   표기(동은 상단 헤더에 이미 있음).

### 신규 반영

4. **서명 이미지**: 방문 샘플에 합성 서명(데모용, 실제 SignaturePad 아님) 이미지를 확인란에
   삽입 — 호수 텍스트 옆에 나란히 배치. **미방문 샘플은 서명을 안 넣었다** — 세대 부재가
   미방문 간이점검의 실제 조건이라 서명 자체가 존재할 수 없기 때문(제 판단, 아래 "확인
   필요 사항" 참고).
5. **기타사항 실측 3종 — 미방문도 동일 형식**: 이전엔 미방문 샘플의 기타사항을 비워뒀는데,
   이번 지시로 미방문도 "부하 X A, IGR X mA, 절연 X MΩ" 형식을 방문과 동일하게 넣도록
   수정(미방문 샘플에 부하전류 8.4A 추가 — EPS실 간이점검에서도 회로 전체 부하전류는 잴
   수 있다는 전제).

### ⚠️ 확인 필요 사항 (제 판단으로 처리했으나 CEO 확인 권장)

1. **관리사무소 신설 줄의 정확한 위치** — 원본엔 사전 인쇄 자리가 없어 확인란 아래 빈
   여백에 새로 넣었다. 이게 CEO 의도(예: 원본_세대점검표_CEO첨부.hwp의 실제 위치)와
   다르면 좌표를 알려주시면 바로 맞추겠다.
2. **미방문 샘플의 서명 생략** — "확인란 호/서명"을 "방문·미방문 공통"으로 요구했지만,
   미방문(세대 부재)에 실제로 없는 서명을 만들어 넣는 건 사실과 다른 내용을 채우는 것이라
   판단해 **호수만 넣고 서명은 비웠다**(원본 그대로 공란). 자가 실패 조건의 "확인란 호/서명"
   문구를 "호는 필수, 서명은 있을 때만"으로 해석했다 — 이 해석이 틀렸다면(즉 미방문에도
   반드시 서명 이미지를 넣어야 한다면) 알려주시기 바란다.

### 잔여 리스크 (본작업 전 확인/처리 필요)

1. **스탬프 폰트**: 로컬 샘플은 Windows 시스템 폰트(맑은 고딕, `C:\Windows\Fonts\malgun.ttf`)를
   스크립트에서 직접 읽어 검증했다 — 이 폰트는 MS 라이선스라 **리포에 커밋 안 했고 못 한다**.
   이 저장소에 이미 있는 `NotoSansKR-Bold.woff2`는 서브셋이라 ○(U+25CB) 글리프가 없음을
   실측 확인(`fontkit.hasGlyphForCodePoint(0x25cb) === false`). **실제 배포 전 라이선스
   확인된 풀커버리지 한글 폰트를 별도로 소싱해야 한다** — 이게 없으면 서버에서 이 코드가
   동작하지 않는다(가장 중요한 잔여 리스크).
2. **비고 열 실사용폭이 매우 좁음(≈33pt)** — 현장 메모는 사실상 4~6자로 강제 압축된다.
   실사용에서 부족하면 2줄 허용이나 폰트 추가 축소를 검토해야 한다.
3. **좌표는 이 특정 원본 파일에 대해서만 검증됨** — `PATH_A_COORDINATES.md` 참고. 원본이
   재발급되면 좌표 재검증 필요.
4. **AI 생성 파이프라인 미연결** — `unit-inspection-ai-diagnosis.ts`(SYSTEM_PROMPT 등)는 아직
   구 스키마(violations[] 나열형)에 머물러 있다. 이번 샘플의 2p 진단은 전부 손으로 만든
   mock 데이터다. 실제 Claude 프롬프트를 v2 스키마(diagnosis 4절+summary 문단+recommendations)로
   다시 쓰는 작업은 본작업 범위로 남겨둠 — 이번엔 "재샘플만" 지시라 손대지 않았다.
5. **구 경로(C) 코드 존치** — `UnitInspectionElement`/`renderUnitInspectionPdf`가 여전히
   파일에 남아있다(호출부도 그대로). 삭제·정리는 본작업 승인 후 논의.
6. 표 격자선의 정확한 벡터 좌표는 이번에 못 뽑았다(pdfjs `getOperatorList()` 포맷 이슈) —
   대신 실측 렌더링 육안 대조로 검증했다. 더 정밀한 값이 필요하면 재작업 필요(`PATH_A_COORDINATES.md`
   "잔여 리스크" 참고).

### IT QA 지적 3건 — 전부 해결

1. **하단 관리사무소 잘림** → 해결. 원인: 위험요인 열을 새로 만들며 비고(166→140px)·점검결과
   (118→100px) 폭까지 줄여서 `estimateTableHeight`의 줄바꿈 cpl 상수가 실제와 안 맞았던 것.
   **비고·점검결과 폭은 원래값(166/118)으로 되돌리고, 새 열 폭은 전부 확인사항(flex)에서만
   가져오는 방식으로 재조정** — 확인사항 cpl도 33→31로 같이 낮췄다. 재샘플에서 정상 확인.
2. **N/A → "/" 표기** → 해결. `checklistResultSymbol`이 N/A를 "해당없음" 문자열로 렌더링하던
   걸 원본 규칙대로 기호 "/"로 변경(비고란의 "해당없음" 텍스트는 그대로 유지 — 그건 별개 필드).
   **미방문 간이점검 샘플 1건을 추가로 생성**해 N/A 9항목이 전부 "/"로 뜨는 것 확인
   (`samples/sample-unit-inspection-unvisited-2026-09-22-page1.png`).
3. **STATUS.md 문서 드리프트** → 해결. STATUS.md 3절 대조표를 5열 반영본으로 갱신.

### 작업 중 발견한 이슈 + 조치

1. **"○"(U+25CB) 폰트 렌더링 실패** — 번들 NotoSansKR 서브셋에 이 글리프가 없어 satori가
   빈 네모로 렌더링(`Failed to load dynamic font for ○` 에러 실측 확인). 텍스트 대신 CSS로
   그린 원(`ResultCircle`, border-radius 사각형)으로 대체해 해결. "×"(U+00D7)는 서브셋에
   있어 텍스트 그대로 사용.
2. **표 폭 재배분 시 높이 추정 상수 미스매치** — 위험요인 열을 만들며 처음엔 비고/점검결과
   폭을 줄였는데, `estimateTableHeight`의 줄바꿈 cpl 상수를 안 맞춰서 표 전체 높이가
   과소추정되고 하단 "관리사무소" 줄이 페이지 경계에서 잘리는 버그가 실제 렌더링에서
   나왔다. **비고(166px)·점검결과(118px) 폭은 기존값 그대로 두고, 새 열 폭은 전부
   확인사항(flex) 열에서만 가져오는 방식으로 수정**해 해결 — 확인사항 cpl도 33→31로 소폭
   하향 조정. 이 파일은 이런 "폭 바꾸면 반드시 그 열의 cpl 상수도 같이 재검증" 패턴이
   과거에도 여러 번 반복된 곳(코드 주석에 이력 있음)이라, 앞으로 이 표를 또 건드릴 땐 항상
   실제 렌더링(PNG)으로 재확인할 것.
3. **`renderUnitInspectionPdf` 호출부가 6곳**(worker/apt-manager 제출 API, admin pdf/reissue-pdf
   API, ai-diagnosis 사후보정, backfill 스크립트) — `circuitBreakerCount`를 실측/기준 계산에
   써야 해서 `UnitInspectionPdfData` 타입에 추가하고 6곳 전부에 배선했다. 기존 DB 컬럼
   재사용이라 마이그레이션 불필요.
