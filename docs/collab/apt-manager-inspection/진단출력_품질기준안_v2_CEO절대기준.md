## 2. 「진짜 진단·종합총평」작성 기준

진단·총평은 **2페이지(또는 동등 화면) AI 안전진단**에만 둔다. 1페이지 별지15에 쓰지 않는다.

### 2-1. 나열 = 불합격 (정의)

다음에 해당하면 진단·총평이 **아니다**.

- 부적합 항목을 번호만 매겨 다시 적음
- 실측값만 줄줄이 씀 (해석·인과·우선순위 없음)
- 「○는 적합, ×는 부적합입니다」식 결과 통보만
- 표·체크리스트를 문장으로 옮긴 것
- 총평인데 권고 목록을 붙여 넣은 것

### 2-2. 진짜 진단 — 필수 문장 구조

**진단 본문(종합총평 위 또는 핵심 블록)** 은 아래 4절을 **모두** 갖춘다. 한 절이 빠져도 불합격.

1. **관찰 요약 (1~2문장)**  
   무엇을 어떻게 봤는지. 나열이 아니라 한 장면으로.  
   예: `거실 분전반 하부 배선 피복 손상과 주회로 절연저항 저하가 함께 확인됩니다.`

2. **의미·인과 (1~2문장)**  
 실측/기준 관계를 **한 줄로 해석**.  
   예: `절연저항 0.08MΩ은 기준 0.11MΩ에 못 미쳐, 누설 가능성이 있는 상태로 보입니다.`

3. **우선순위 (1문장)**  
   여러 ×가 있을 때 **지금 먼저 볼 것** 하나.  
   예: `우선 주회로 절연·누설 구간을 확인하고, 이어 에어컨 실외기 접지 상태를 점검하는 순서를 권합니다.`

4. **한계·전제 (1문장, 짧게)**  
   제공 범위·현장 한계를 긍정적으로.  
   예: `본 안내는 점검 기록과 실측을 바탕으로 한 상세 설명이며, 공식 적합·부적합 표기는 1페이지 점검기록표를 따릅니다.`

### 2-3. 진짜 종합총평 — 필수 문장 구조

총평은 **문단 1개(2~4문장)**. 불릿 금지. 아래 순서를 지킨다.

1. **한 줄 판단** — 이 세대 전기 상태를 한 문장으로 (나열 금지)  
   예: `이번 점검은 절연·누설 관련 부적합이 핵심인 세대로 정리됩니다.`
2. **근거 한 줄** — 대표 실측·현장 사실 **하나만** 들어 뒷받침  
   예: `주회로 절연저항이 기준에 못 미치고, 거실 분전반 하부 피복 손상이 함께 있었습니다.`
3. **다음 한 줄** — 관리소·입주민이 취할 **방향** (구체 공법·자재 지정 금지)  
   예: `관리사무소와 상의해 해당 구간의 재확인·보수를 先行하는 것이 좋습니다.`

**총평 불합격 예 (나열형)**  
`부적합: 절연2, 배선1, 배선기구1, 접지1. 절연 0.08, 누설 3.5, 부하 15.2.`

**총평 합격 예**  
`이번 점검은 절연·누설이 핵심인 세대로 정리됩니다. 주회로 절연저항이 기준에 못 미치고 거실 분전반 하부 피복 손상이 함께 있었습니다. 관리사무소와 상의해 해당 구간 재확인·보수를 先行하는 것이 좋습니다.`

### 2-4. 실측 vs 기준 표 (진단의 근거 레이어)

- 위치: 2페이지만. 열 = 항목 · 실측 · 기준 · 판정 한 줄
- 필수 후보: 절연저항, 누설전류, 부하전류, 접지저항(해당·측정 시). 없으면 「미측정」
- 표만 있고 2-2·2-3 문장이 없으면 **진단 불합격** (표는 근거, 진단은 문장)

### 2-5. 권고 목록 (총평과 분리)

- 총평 ≠ 권고. 권고는 총평 **아래** 불릿
- 기본 1~3, 상한 5. 형식: `[대상] + [사실] + [다음 행동]`
- 금지: 과잉 공포, 미검증 시공·자재 지시, 과태료·불법 단정, 당사 시공 약속
- 「자체 권장」별도 박스·타 브랜드명으로 이중화 금지 → **권고사항 하나**

### 2-6. 1p / 2p 라벨 (혼동 방지)

| 위치 | 필수 라벨 |
|------|-----------|
| 1p | 원본 그대로 `[별지 제15호 서식] …점검기록표` |
| 2p 상단 | `AI 안전진단 결과 (상세)` |
| 2p 고정 한 줄 | `아래는 1페이지 법정 점검기록표를 보완하는 상세 진단입니다. 공식 ○·×·/ 표기는 1페이지를 따릅니다.` |

## 3. 검수 체크리스트 (제출 전 필수)

검수자(서비스·제품 / 총괄)가 샘플마다 채운다. **한 줄이라도 ×면 제출 금지.**

### A. 서식 0%

- [ ] F01–F14 전부 ○
- [ ] 원본과 나란히 대조한 근거(파일명·일시) 기록
- [ ] 유사·재구성 서식 아님

### B. 진단·총평

- [ ] 진단 4절(관찰·의미·우선·한계) 모두 존재
- [ ] 총평이 불릿·숫자 나열이 아님 (한 줄 판단→근거→다음)
- [ ] 실측표만으로 진단/총평을 대체하지 않음
- [ ] 권고 ≤5, 총평과 분리, 이중 브랜드 박스 없음
- [ ] 금지 표현 없음

### C. 완성도 (어설프면 불가)

- [ ] 오탈자·건수 불일치(총평 vs 본문) 없음
- [ ] 1p에 AI/권고/상세박스 침투 없음
- [ ] “나중에 고치면 됨” 수준의 미완 문장 없음
- [ ] 미달 시 제출하지 않고 **「처음부터 불가」**로 총괄에 보고

### 판정 기입란

```
판정: 통과 / 폐기(처음부터 불가)
실패 사유:
검수자:
일시:
```
