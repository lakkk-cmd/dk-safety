# 진단 출력 품질 기준안 (파일럿)

- 대상: 우리집안심전기 · apt-manager 세대점검표·AI 진단결과
- 날짜: 2026-09-22
- 작성: 서비스·제품팀 (총괄 지시)
- 범위: 샘플·본작업 공통 **문구·구조 기준** (코드 수정·배포 없음)
- 이번 범위 밖: 사진, 양호·주의·위험 3단계 배지

---

## 0. 문서 역할 한 줄

| 산출물 | 역할 | 표기 |
|--------|------|------|
| 1페이지 · 별지 제15호 | 법정 점검기록표 (관리사무소 명의) | ○ 적합 · × 부적합 · / 해당없음 |
| 2페이지 · AI 안전진단 | 실측 해설·권고 (이해·후속 안내) | 실측 / 기준 표 + 총평 + 권고 목록 |

두 페이지는 **같은 세대를 다루되 목적이 다름**. 서로 대체·혼용 라벨 금지.

## 1. 「실측 vs 기준」구조화 — 필수 항목

법정 1페이지 표를 깨지 않는다. 구조화 박스는 **2페이지(또는 동등 화면)** 에만 둔다.

### 1-1. 행(필드) 필수 세트

각 측정 항목은 아래 열을 모두 채운다. 값이 없으면 해당 행을 `/`(해당없음) 또는 「미측정」으로 명시하고 빈칸으로 두지 않는다.

| 열 | 설명 | 예 |
|----|------|----|
| 항목명 | 입주민·관리소가 바로 읽는 이름 | 주회로 절연저항 |
| 실측 | 숫자 + 단위 | 12.4 MΩ |
| 기준 | 숫자·범위 + 단위 (설정·고시 매핑값) | 0.2 MΩ 이상 |
| 판정 한 줄 | 짧고 중립 | 기준을 충족합니다 |
| 대응 설비(선택) | 별지15 카테고리와 연결 시 | 절연(누전) |

### 1-2. 필수 측정 항목 (파일럿 최소)

우선순위 순. 샘플에 전부 넣을 수 없으면 **1~4를 먼저** 넣고, 미측정은 「미측정」으로 표기.

1. **절연저항** (주회로 · 분기회로 — 가능하면 구분)
2. **누설전류** (또는 누전차단기 동작 확인 결과와 연계 수치)
3. **부하전류** (주회로 또는 대표 분기 · 차단기 정격과 대비)
4. **접지저항** (금속제 분전반 등 해당 시)
5. **차단기·누전차단기 상태** (동작시험 결과 — 수치 없으면 적합/부적합 문장)
6. **기타 실측** (전압 등 — 현장에서 잰 경우만)

수치 기준값(몇 MΩ·몇 mA)은 **제품 측정설정·관련 고시/기술기준 매핑**에서 가져온다. 이 문서에서 임의 수치를 확정하지 않는다.

### 1-3. 표시 규칙

- 한 항목 = 한 행. 여러 수치를 한 문장에 몰아넣지 않는다.
- 단위 생략 금지 (MΩ, mA, A, Ω, V).
- 실측이 기준을 벗어나면 판정 한 줄에 **사실만** 쓴다. (“위험합니다” 단독 금지 → 「기준보다 낮습니다」 등)
- 기존 문장 설명은 표 **아래**에 1~2문장으로 병행 가능 (HANDOFF 승인 사항).

### 1-4. 문장 톤 (관리사무소 · 입주민 공통)

- 한 문장 40자 안쪽 권장. 전문 약어는 풀어 쓴 뒤 병기.
- 주어를 분명히: 「이번 점검에서 ○○은 …」
- 존댓말, 짧은 평서문. 명령·협박·과장 금지.
- 관리사무소 화면/PDF: 단지 운영에 쓸 수 있게 항목명·호수 명확.
- 입주민 안내 문장: 같은 사실을 더 쉬운 말로 한 번 더 써도 됨 (별도 블록 가능).

**톤 예시**

| 상황 | 권장 | 비권장 |
|------|------|--------|
| 기준 충족 | 주회로 절연저항은 기준을 충족합니다. | 안전합니다! / 이상무 |
| 기준 미만 | 주회로 절연저항이 기준보다 낮습니다. | 감전·화재 위험, 즉시 대피하세요 |
| 미측정 | 이번 점검에서 접지저항은 측정하지 않았습니다. | (공란) / N/A만 표기 |

## 2. 「권고」목록 작성 원칙

### 2-1. 종합총평 vs 권고 — 구분

| | 종합총평 | 권고 |
|--|----------|------|
| 역할 | 세대 전체를 **한눈에 요약** | **다음에 할 일**을 짧게 나열 |
| 형태 | 문단 2~4문장 | 불릿 목록 |
| 내용 | 적합·부적합 요지, 주요 실측 한 줄 | 조치·재확인·전문상담 안내 |
| 금지 | 체크리스트처럼 늘리기 | 총평 문장을 그대로 복붙 |

작성 순서: (1) 실측/기준 표 → (2) 종합총평 → (3) 권고 목록.

### 2-2. 개수 상한

- **기본 1~3개**, **상한 5개**.
- 부적합(×)이 많을 때도 5개를 넘기지 말고, 우선순위 높은 것만 남긴다.
- 전부 적합(○)이면 권고는 **0~1개** (예: 다음 정기 점검 시기 안내) 또는 「추가 권고 없음」 한 줄.

### 2-3. 권고 한 줄 형식

`[대상] + [관찰 사실] + [다음 행동]`  
예: 욕실 콘센트 회로 — 인체 감전보호용 누전차단기 동작이 불안정합니다. 관리사무소에 점검·교체 상담을 요청해 주세요.

### 2-4. 금지 표현 (내부 품질)

- 과잉 공포: 「치명적」「곧 화재」「당장 대피」「사망」 등
- 미검증 시공 지시: 「○○로 교체하세요」「전선 잘라 이으세요」 등 **구체 공법·자재 지정**
- 책임 전가·확정 단정: 「과태료 부과됩니다」「불법입니다」(법적 효과는 제안·진단 문구에 넣지 않음)
- 당사 시공 약속처럼 읽히는 말: 「저희가 고쳐 드립니다」(역할: 공고·AI 진단·기술 지원)
- 총평과 중복되는 장문 복붙

### 2-5. 권장 표현 방향 (긍정·제공 범위와 정합)

- 「전문 전기공사·관리사무소와 상의해 주세요」
- 「재측정·재점검이 필요합니다」
- 「관련 설비 상태를 확인해 주세요」
- 제공 가능하면: 「기술 지원·진단 결과 설명은 당사에 문의해 주세요」

## 3. 별지15(O/X) vs 2페이지 상세진단 — 카피·레이블

혼동 방지용 **고정 라벨** (샘플부터 동일 문자열 권장).

### 3-1. 페이지·섹션 제목

| 위치 | 권장 라벨 | 쓰지 말 것 |
|------|-----------|------------|
| 1p 상단 | `[별지 제15호 서식] 공동주택 세대내 전기설비 점검기록표` | AI 진단서, 상세리포트 |
| 1p 결과 열 | `점검 결과` + 비고 안내 `○(적합) ×(부적합) /(해당없음)` | 점수, 등급, 양호/주의/위험 |
| 2p 상단 | `AI 안전진단 결과 (상세)` | 별지 제15호, 법정 점검표 |
| 2p 표 | `실측과 기준 비교` | 점검 결과(○×) |
| 2p 총평 | `종합총평` | 최종 합격/불합격 |
| 2p 목록 | `권고사항` | 필수 조치 명령, 시공 지시서 |

### 3-2. 한 줄 안내문 (2p 상단 고정 카피 제안)

> 아래는 법정 점검기록표(1페이지)를 보완하는 **상세 진단 안내**입니다. 적합·부적합 공식 표기는 1페이지 ○×/ 를 따릅니다.

### 3-3. 교차 참조

- 2p 권고·총평에서 1p를 가리킬 때: 「1페이지 점검기록표 ○번 항목」처럼 **페이지를 명시**.
- 1p 비고에 AI 문장을 길게 넣지 않는다. 상세는 2p로.

### 3-4. 하단 명의

- 1p 하단: `{아파트명} 관리사무소` (원본·CEO 확정)
- 2p 진단 블록: 기술 지원·AI 진단 문구는 **제공 범위만 긍정 서술**. ‘대행하지 않음’ 대비표는 넣지 않음 (CEO 원칙).

## 4. 샘플 검수 체크 (CEO 확인용 보완)

HANDOFF 샘플 수락 기준에 아래를 추가 확인한다.

- [ ] 2p에 실측/기준 표가 있고, 필수 항목(절연·누설·부하·접지 해당 시)이 행으로 보임
- [ ] 총평 문단과 권고 목록이 **시각·제목으로 분리**
- [ ] 권고 ≤ 5, 금지 표현 없음
- [ ] 1p 제목·기호와 2p 제목·라벨이 서로 바뀌지 않음
- [ ] 2p 상단에 「상세 진단 안내 / 공식 ○×는 1페이지」 한 줄 존재
