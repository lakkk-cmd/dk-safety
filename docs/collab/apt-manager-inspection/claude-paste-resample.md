## 필수 수정
1. 1페이지 비고란에서 「AI 판정」문구 제거·최소화. 실측 해설·AI 상세는 2페이지만.
2. 2페이지 제목: `AI 안전진단 결과 (상세)`
   상단 고정카피: `아래는 법정 점검기록표(1페이지)를 보완하는 상세 진단 안내입니다. 적합·부적합 공식 표기는 1페이지 ○×/ 를 따릅니다.`
3. 종합총평의 부적합 건수 = 실제로 표시된 부적합(×) 건수와 **반드시 일치**
4. 「우리집 전기주치의 자체 권장사항」과 「권고사항」이중화 금지 → **권고사항 목록 하나로 통합** (수명 권장은 권고 불릿에 편입)
5. 부적합 설명에서 「감전·화재 위험」나열·공포 톤 완화. 사실 + 다음 행동. 시공지시·과태료단정·당사시공약속 금지.
6. 가능하면 실측표에 접지저항 행 또는 「미측정」명시.
7. IT: 하단 `{아파트명} 관리사무소` 잘림 없는지 재확인. N/A는 **`/`**. ○는 ResultCircle 유지(텍스트 ○ 금지). STATUS.md를 5열 기준으로 코드와 동기화.
